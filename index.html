Frequently Asked Questions

Everything you need to know about PinNote, system requirements, and security.

Most modern desktop note apps run on Electron or WebView2 frameworks, consuming 300 MB to 1 GB+ of RAM. PinNote is built with a high-performance native Qt6 (C++ core) architecture, using only ~20 MB of RAM while maintaining smooth GPU hardware acceleration.

PinNote features a dedicated pin button on its title bar and a global Ctrl+P (or Cmd+P on macOS) shortcut. Clicking Pin toggles Always-on-Top mode with an active royal blue indicator, ensuring your notes remain visible above code editors, web browsers, and full-screen tools.

Auto-transparency smoothly fades the PinNote window to your preferred opacity (e.g., 50%) when you are not interacting with it, keeping your screen clutter-free. The moment you move your mouse, click, or type, it instantly returns to 100% opacity.

PinNote is 100% offline and private. There are no accounts, cloud sync servers, or background telemetries. All notes, tables, screenshots, and window preferences are saved locally to your device's user profile directory at ~/.pinnote/data.json.

Yes! You can paste rich tables from Microsoft Word, Excel, and Google Gemini, as well as raw Markdown tables. You can also paste screenshots directly from Snipping Tool (Win+Shift+S) and resize them using interactive corner handles.

PinNote is fully supported on 64-bit Windows 11 and Windows 10, as well as macOS 12+ (Monterey, Ventura, Sonoma, Sequoia) on both Apple Silicon (M1/M2/M3/M4) and Intel architectures.

Yes, PinNote is 100% free software released under the permissive MIT Open Source License. You are free to inspect the source code, build it locally, or download the pre-compiled releases.
